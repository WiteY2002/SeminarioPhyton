# Simulador de competencia sobre cocina

#

En este programa se simula una competencia de cocina que tiene varias rondas, en la que los participantes reciben puntos por 3 jueces y en la cual se suma los puntos de los jueces para determinar el ganador de la ronda y acumular los puntos para mostrar una tabla final con los puntos totales de los cocineros, rondas ganadas,cantidad de rondas ganadas y promedio de puntos.


# Requisitos

* Python 3.12.9 en adelante
* Jupyter



# dependencias

En este programa no se usa ninguna dependencia por lo que no es necesaria la instalacion de dependencias externas.


# Ejecucion del programa 

1. Abrir el proyecto 
2. Ir a la carpeta `notebooks`
3. Abrir el archivo `ejercicio10.ipynb`
4. Ejecutar las celdas (en orden)


# Estructura del proyecto

* `src/`: estan ubicadas las funciones del programa
* `notebooks/`: donde se encuentra el main(ejecucion del programa )
